# AppAcademia

Estrutura inicial do app Android da Academia Garagem Aço.

- Stack: Kotlin + Jetpack Compose + Navigation Compose
- Telas previstas: login, dashboard, financeiro, presença
- Integração futura: API central do sistema web

## Como usar no Android Studio

1. Abra o Android Studio
2. Escolha "Open an Existing Project"
3. Selecione a pasta: `C:\wamp64\www\academia\android\AppAcademia`
4. Aguarde sincronização do Gradle
5. Conecte um dispositivo/emulador e rode o app

## Observações

- As telas são skeletons para validação de estrutura e compilação.
- A integração com a API será adicionada posteriormente.
